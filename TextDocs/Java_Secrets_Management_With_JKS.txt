Example Code (AES-GCM)
The following is a standard way to implement secure AES encryption in Java:
java
import javax.crypto.Cipher;
import javax.crypto.KeyGenerator;
import javax.crypto.SecretKey;
import javax.crypto.spec.GCMParameterSpec;
import java.security.SecureRandom;
import java.util.Base64;

public class EncryptionUtil {
    private static final String ALGORITHM = "AES/GCM/NoPadding";
    private static final int TAG_LENGTH_BIT = 128;
    private static final int IV_LENGTH_BYTE = 12;

    public static String encrypt(String input, SecretKey key) throws Exception {
        Cipher cipher = Cipher.getInstance(ALGORITHM);
        byte[] iv = new byte[IV_LENGTH_BYTE];
        new SecureRandom().nextBytes(iv); // Generate random IV
        
        cipher.init(Cipher.ENCRYPT_MODE, key, new GCMParameterSpec(TAG_LENGTH_BIT, iv));
        byte[] cipherText = cipher.doFinal(input.getBytes());
        
        // Return IV + CipherText encoded in Base64
        byte[] combined = new byte[iv.length + cipherText.length];
        System.arraycopy(iv, 0, combined, 0, iv.length);
        System.arraycopy(cipherText, 0, combined, iv.length, cipherText.length);
        return Base64.getEncoder().encodeToString(combined);
    }

    public static String decrypt(String combinedBase64, SecretKey key) throws Exception {
        byte[] combined = Base64.getDecoder().decode(combinedBase64);
        
        // Extract IV and CipherText
        byte[] iv = new byte[IV_LENGTH_BYTE];
        System.arraycopy(combined, 0, iv, 0, iv.length);
        byte[] cipherText = new byte[combined.length - iv.length];
        System.arraycopy(combined, iv.length, cipherText, 0, cipherText.length);

        Cipher cipher = Cipher.getInstance(ALGORITHM);
        cipher.init(Cipher.DECRYPT_MODE, key, new GCMParameterSpec(TAG_LENGTH_BIT, iv));
        return new String(cipher.doFinal(cipherText));
    }
}

Step 1: Create a KeyStore Programmatically
This example demonstrates how to generate a new AES-256 key, save it to a .p12 file, and later retrieve it for decryption.

java
import javax.crypto.KeyGenerator;
import javax.crypto.SecretKey;
import java.io.File;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.security.KeyStore;

public class KeyStoreManager {
    private static final String KEYSTORE_TYPE = "PKCS12";
    private static final String KEYSTORE_PATH = "my_local_keys.p12";
    private static final String ALIAS = "my-symmetric-key";
    private static final char[] PASSWORD = "securePassword123".toCharArray();

    public static void main(String[] args) throws Exception {
        // 1. Generate a new Secret Key (AES-256)
        KeyGenerator keyGen = KeyGenerator.getInstance("AES");
        keyGen.init(256);
        SecretKey secretKey = keyGen.generateKey();

        // 2. Save Key to KeyStore
        saveKeyToStore(secretKey);
        System.out.println("Key saved to " + KEYSTORE_PATH);

        // 3. Load Key from KeyStore
        SecretKey loadedKey = loadKeyFromStore();
        System.out.println("Successfully loaded key with algorithm: " + loadedKey.getAlgorithm());
    }

    public static void saveKeyToStore(SecretKey key) throws Exception {
        KeyStore keyStore = KeyStore.getInstance(KEYSTORE_TYPE);
        
        // Initialize new or existing store
        File file = new File(KEYSTORE_PATH);
        if (file.exists()) {
            try (FileInputStream fis = new FileInputStream(file)) {
                keyStore.load(fis, PASSWORD);
            }
        } else {
            keyStore.load(null, PASSWORD);
        }

        // Store the key entry
        KeyStore.SecretKeyEntry secretKeyEntry = new KeyStore.SecretKeyEntry(key);
        KeyStore.ProtectionParameter protectionParam = new KeyStore.PasswordProtection(PASSWORD);
        keyStore.setEntry(ALIAS, secretKeyEntry, protectionParam);

        // Write back to disk
        try (FileOutputStream fos = new FileOutputStream(KEYSTORE_PATH)) {
            keyStore.store(fos, PASSWORD);
        }
    }

    public static SecretKey loadKeyFromStore() throws Exception {
        KeyStore keyStore = KeyStore.getInstance(KEYSTORE_TYPE);
        try (FileInputStream fis = new FileInputStream(KEYSTORE_PATH)) {
            keyStore.load(fis, PASSWORD);
        }
        return (SecretKey) keyStore.getKey(ALIAS, PASSWORD);
    }
}
Use code with caution.

Key Components Explained
KeyStore Instance: Use KeyStore.getInstance("PKCS12") for modern standards. Older JKS format is being phased out.
ProtectionParameter: This wraps your password and is required when saving or retrieving secret keys.
Alias: A unique string (like a filename) used to identify a specific key within the store.
SecretKeyEntry: Unlike public/private key pairs which use certificates, symmetric keys are stored as "SecretKey" entries.

To automate encryption from the command line using your Java KeyStore, you can use a Shell script that creates a temporary Java "script" on the fly. 
This approach utilizes JEP 330 (available in Java 11+), which allows you to run Java source files directly without manual compilation.
The Shell Script (encrypt-pass.sh)
Copy the following into a file named encrypt-pass.sh and give it execution permissions with chmod +x encrypt-pass.sh. 
bash
#!/bin/bash

# Configuration - update these to match your setup
KEYSTORE="my_local_keys.p12"
STOREPASS="securePassword123"
ALIAS="my-aes-key"
KEYPASS="securePassword123"

# Check if input is provided
if [ -z "$1" ]; then
    echo "Usage: ./encrypt-pass.sh <password_to_encrypt>"
    exit 1
fi

PLAINTEXT=$1

# Use a Here-Doc to run Java directly
java - <<EOF
import javax.crypto.Cipher;
import javax.crypto.SecretKey;
import javax.crypto.spec.GCMParameterSpec;
import java.io.FileInputStream;
import java.security.KeyStore;
import java.security.SecureRandom;
import java.util.Base64;

public class Encryptor {
    public static void main(String[] args) throws Exception {
        // 1. Load the Key
        KeyStore ks = KeyStore.getInstance("PKCS12");
        try (FileInputStream fis = new FileInputStream("$KEYSTORE")) {
            ks.load(fis, "$STOREPASS".toCharArray());
        }
        SecretKey key = (SecretKey) ks.getKey("$ALIAS", "$KEYPASS".toCharArray());

        // 2. Setup AES-GCM
        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        byte[] iv = new byte[12];
        new SecureRandom().nextBytes(iv);
        cipher.init(Cipher.ENCRYPT_MODE, key, new GCMParameterSpec(128, iv));
        
        // 3. Encrypt
        byte[] cipherText = cipher.doFinal("$PLAINTEXT".getBytes());
        
        // 4. Output (IV + Ciphertext) in Base64
        byte[] result = new byte[iv.length + cipherText.length];
        System.arraycopy(iv, 0, result, 0, iv.length);
        System.arraycopy(cipherText, 0, result, iv.length, cipherText.length);
        System.out.println(Base64.getEncoder().encodeToString(result));
    }
}
EOF
Use code with caution.

Run the script: Pass the string you want to encrypt as an argument.

To read your encrypted passwords back, you need to reverse the process by splitting the IV from the Ciphertext and initializing the cipher in DECRYPT_MODE.
The Decryption Shell Script (decrypt-pass.sh)
Create a file named decrypt-pass.sh and make it executable with chmod +x decrypt-pass.sh.
bash
#!/bin/bash

# Configuration (Must match the encryption script)
KEYSTORE="my_local_keys.p12"
STOREPASS="securePassword123"
ALIAS="my-aes-key"
KEYPASS="securePassword123"

if [ -z "$1" ]; then
    echo "Usage: ./decrypt-pass.sh <base64_encrypted_string>"
    exit 1
fi

ENCRYPTED_B64=$1

java - <<EOF
import javax.crypto.Cipher;
import javax.crypto.SecretKey;
import javax.crypto.spec.GCMParameterSpec;
import java.io.FileInputStream;
import java.security.KeyStore;
import java.util.Base64;

public class Decryptor {
    public static void main(String[] args) throws Exception {
        // 1. Load the Key from KeyStore
        KeyStore ks = KeyStore.getInstance("PKCS12");
        try (FileInputStream fis = new FileInputStream("$KEYSTORE")) {
            ks.load(fis, "$STOREPASS".toCharArray());
        }
        SecretKey key = (SecretKey) ks.getKey("$ALIAS", "$KEYPASS".toCharArray());

        // 2. Decode the Base64 input
        byte[] combined = Base64.getDecoder().decode("$ENCRYPTED_B64");

        // 3. Extract IV (first 12 bytes) and Ciphertext
        int ivLength = 12; // Must match the length used in encryption
        byte[] iv = new byte[ivLength];
        System.arraycopy(combined, 0, iv, 0, ivLength);
        
        byte[] cipherText = new byte[combined.length - ivLength];
        System.arraycopy(combined, ivLength, cipherText, 0, cipherText.length);

        // 4. Initialize Cipher in Decrypt Mode
        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        cipher.init(Cipher.DECRYPT_MODE, key, new GCMParameterSpec(128, iv));
        
        // 5. Decrypt and Print
        byte[] decrypted = cipher.doFinal(cipherText);
        System.out.println(new String(decrypted));
    }
}
EOF
Use code with caution.

How it works:
Extraction: The script assumes the first 12 bytes of the Base64 string are the IV (Initialization Vector) and the rest is the encrypted data.
GCM Integrity: Because we used AES-GCM, the decryption will automatically fail (throw an exception) if the ciphertext has been tampered with or if the wrong key/password is used.
One-Liner Execution: Just like the encryption script, this runs the Java code in-memory without creating permanent .class files.

difference between STOREPASS and KEYPASS?
The primary difference is their scope of protection: STOREPASS secures the entire file, while KEYPASS secures an individual entry inside that file. 
STOREPASS (Keystore Password): Used to protect the integrity of the entire keystore file. You need it to open the file and list its contents.
KEYPASS (Key Password): Used to decrypt a specific private or secret key stored inside the keystore. Each entry in a keystore can technically have its own unique key password. 
Stack Overflow
Stack Overflow

Key Differences & Behavior
Access Hierarchy: You typically provide the STOREPASS first to "unlock" the store, and then the KEYPASS to "unlock" the specific key for encryption or decryption.
PKCS12 Default (Modern Java): In the modern PKCS12 format (default since Java 9), Java often enforces that the STOREPASS and KEYPASS be the same for better interoperability with other tools like OpenSSL or web browsers.
Fallback: If you don't specify a KEYPASS when using keytool, it will automatically attempt to use the STOREPASS to recover the key.
Legacy Formats: Older formats like JCEKS or JKS fully supported having different passwords for the store and each individual key.

4. Important Security Warnings
Avoid setx: Do not use the setx command for passwords. It creates persistent system-wide variables that stay in the registry in plain text, making them visible to any user or script on the machine.
Secure Strings: If you are staying within PowerShell, use ConvertTo-SecureString to keep the password encrypted in memory.
Logging: Be careful not to Write-Host or print your decrypted password to the console, as it may be captured in transcript logs or command history.
